- Compiles clean

## Scope criteria (beauty / human)

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Brand read | Generic / off-brief | Partial green/fintech cues | Clear deep-green trustworthy fintech |
| Token discipline | Many raw hex/px | Mixed | Brand via tokens/theme/sx |
| Page structure | Incomplete | Hero or features only | Hero + features + footer |
| Calm density | Cramped or empty | Acceptable | Comfortable fintech density |

Beauty is human-graded against the brand brief in `reference/`.
