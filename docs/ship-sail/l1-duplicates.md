## What this is and isn't

* **Duplicate** components re-implement an L1 element. The next
cutover wave deletes them (this job does NOT touch them).
* **Orphan** components have a controller but no source, an L1
cutover residue. The existing `PRIMITIVES-DISSOLUTION.md` covers
them by hand; this report is the mechanical cross-check.
* **Novel** components have no L1 equivalent; they earn their
keep by domain (charts, canvas, code editor, ...).
